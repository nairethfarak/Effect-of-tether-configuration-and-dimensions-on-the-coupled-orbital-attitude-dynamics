# Effect-of-tether-configuration-and-dimensions-on-the-coupled-orbital-attitude-dynamics

This project investigates the influence of electrodynamic tether configuration and dimensions on the coupled orbital and attitude dynamics of a spacecraft system.

The study evaluates how changes in tether parameters affect the spacecraft's orbital response, attitude motion, and libration behavior, providing insight into the dynamic implications of tether sizing and configuration.

***Note:*** This repository presents the methodology of the study. The simulation source code is not included.

## Objective
The main objective is to characterize the coupled orbital and attitude response of an electrodynamic tethered spacecraft system across different tether configurations and dimensions.

The study focuses on evaluating how parameters such as tether length and cross-sectional dimensions influence the dynamic behavior of the system.

A particular emphasis is placed on identifying trends in the orbital and attitude response and evaluating the relative influence of the different tether parameters.

## Parametric study
The study uses a parametric sweep to investigate the influence of tether configuration and dimensions on the dynamic response.

The parameters considered include tether length, cross-sectional dimensions, tether mass, and tether configuration.

The simulations are used to characterize the resulting changes in:
- Orbital altitude and trajectory.
- Orbital state.
- Attitude response.
- Libration motion.
- Dynamic stability.

Configurations with matched length and mass are also considered to isolate the influence of tether cross-sectional characteristics.

## Main research questions

The study addresses the following questions:

- How does tether length affect the coupled orbital-attitude response?
- How does tether cross-section influence the dynamic behavior?
- How does tether mass affect the response when length is held constant?
- What differences arise between configurations with matched length and mass?
- Which tether parameter produces the strongest influence on attitude and libration behavior?
- How do the observed trends compare qualitatively with results reported for flexible tether models?
